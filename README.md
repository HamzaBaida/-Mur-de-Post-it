## 👤 Auteur

Hamza Baida

---

## 📌 Description

Ce projet est une application web full-stack permettant de gérer un mur de notes (Post-it).
Les utilisateurs peuvent ajouter, modifier, supprimer et personnaliser leurs notes.

---

## 🚀 Fonctionnalités

### ✅ Fonctionnalités de base

* Ajouter une note
* Supprimer une note
* Afficher toutes les notes

### 🔥 Fonctionnalités ajoutées

* ✏️ Modifier une note (édition via formulaire)
* 🕒 Affichage de la date de création
* 🎨 Choix de couleur pour chaque note (sélection par cercles)

---

## 🛠️ Technologies utilisées

* Front-end : HTML, CSS, JavaScript
* Back-end : Node.js avec Express
* Base de données : SQLite

---

## ⚙️ Installation et lancement

### 1. Cloner le projet

```bash
git clone https://github.com/HamzaBaida/-Mur-de-Post-it.git
cd post-it_app/backend
```

### 2. Installer les dépendances

```bash
npm install
```

### 3. Lancer le serveur

```bash
node server.js
```

### 4. Accéder à l'application

Ouvrir dans le navigateur :

```
http://localhost:3000
```
